RENEWABLE ENERGY & SOLAR POWER WEBSITE

PROJECT FILES
- index.html: Website content and page structure.
- style.css: Colours, layout, responsive design and visual effects.
- script.js: Navigation, interactive solar steps, renewable-energy tabs,
  content cards, FAQ, field-visit placeholders and solar calculator.
- images/: The three original team photographs.

HOW TO OPEN THE WEBSITE
1. Extract the ZIP file.
2. Keep index.html, style.css, script.js and the images folder together.
3. Double-click index.html to open the website in a browser.

HOW TO EDIT IT
- Change headings and page text in index.html.
- Change colours, spacing and layout in style.css.
- Change the team, solar information, cards, calculator or interactions in script.js.
- Replace team photographs inside images/ and keep the same filenames,
  or update the image paths in script.js.

NOTE
The original page content and three embedded team photographs were retained.
The photographs have been moved into separate JPG files so the code is easier
 to read and maintain. The calculator is an estimate, not a solar installation quote.
